colombia-open — Design System

Fuente única de verdad de la identidad visual de colombia-open.github.io. Los valores de esta página son el mismo literal que app/globals.css — no hay un paso de build que los genere, así que si cambia uno cambia el otro en el mismo PR (ver .claude/rules/brand.md). Este documento gobierna solo cómo se ve el sitio; qué dataset existe, su conteo de filas, su licencia y su fuente nunca se decide aquí — eso sale siempre del catálogo real en build-time (ver .claude/rules/data-source.md).

Logomarca — "constelación"

Un punto central dorado (el dataset ya curado) con puntos grises alrededor (fuentes todavía sueltas) conectados por líneas finas. Se lee de afuera hacia el centro: cada fuente oficial empieza dispersa, con su propio formato, y converge en un único dataset validado.

Regla dura

  • El punto central es la única señal de "dato ya consolidado" — nunca se usa ese color para otra cosa (alertas, enlaces genéricos, etc.)
  • El inline SVG (components/BrandMark.tsx) y los archivos estáticos (public/brand/*.svg) deben mantenerse idénticos — si cambia uno, cambia el otro

Paleta

--accent y --alert nunca se mezclan: oro es siempre "dato bueno / reciente", terracota es siempre "algo falló". No hay un tercer color semántico todavía.

Regla dura

  • Nada de hex crudo fuera de app/globals.css (los bloques :root / @media (prefers-color-scheme: dark) / [data-theme]) y de esta página
  • Cualquier componente nuevo consume var(--token), nunca un literal
  • --accent es solo para fondos, puntos y bordes — nunca como color de texto de un enlace sobre bg/bg-alt. Como texto da ~1.5:1 de contraste en claro y ~3.3:1 en oscuro, por debajo del 4.5:1 que pide WCAG AA. Los enlaces usan fg + subrayado (ver .dataset-source a, .terminal-note a, .roadmap-cta a en app/globals.css)

Voz

Calmada, precisa, nombra la fuente y la fecha de vigencia del dato — nunca promete "en vivo" cuando es un snapshot cacheado.

Vocabulario ancla

  • fuente
  • vigencia
  • capa
  • procedencia
  • validado

Evitar

  • "en tiempo real" — es un snapshot cacheado, no un stream
  • "garantizado"
  • "oficial" sin matizar — colombia-open no es el DANE, es una capa encima del DANE
  • signos de exclamación cerca de datos o cifras

Reglas duras

Las mismas que gobiernan el resto del sitio (.claude/rules/brand.md, .claude/rules/data-source.md) — esta página no las repite por estilo, las repite porque romperlas rompe la identidad visual o la confianza en el dato.

Marca

  • No introduzcas un color, fuente o radio nuevo sin que primero exista en esta página
  • El punto central del logomark nunca se reutiliza para otra cosa
  • BrandMark.tsx y public/brand/*.svg deben mantenerse idénticos

Datos

  • Nunca se hardcodea un dataset, conteo, licencia o fuente en componentes o contenido
  • Si el fetch del catálogo falla, el build falla — no hay fallback embebido
  • Nunca remover el link a la librería ni a la fuente oficial de cada dataset
